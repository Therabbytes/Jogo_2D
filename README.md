# Jogo_2D
Jogo para os alunos treinarem o versionamento de código.

25/08 - Hoje os alunos foram orientados a criarem um player e uma plataforma dentro da unity vinculado ao git, além de criarem uma pasta para o jogo que foi linkada com a unity, para que cada elemento adicionado e excluido dentro da unity apareça no git e que possamos fazer o commit. Também aprendemos sobre brashs, que são como ramificações dentro do git que permitem com que o usuário partilhe os arquivos do seu código com outros usuários, assim adicionando os elementos dos códigos dentro da main para facilitar o projeto.
